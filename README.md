# Фак(т) зе чек

**Проверка слайдов медицинских докладов с опорой на дословные цитаты.**
Снимаете слайд на телефон — через 15–35 секунд получаете вопросы и комментарии для докладчика.
Каждое утверждение опирается на дословную цитату из проверенного источника, и эту цитату
проверяет код, а не модель.

> **Статус:** в разработке. Проект строится как курс обучения, урок за уроком
> (план — [`docs/Архитектура — учебник.md`](docs/Архитектура%20—%20учебник.md)).

> **Не медицинское изделие.** Инструмент помогает готовить вопросы к докладу и не предназначен
> для принятия клинических решений. Проверяйте первоисточники.

## Зачем

Модератор онкологического вебинара не может быть экспертом во всех темах. Языковые модели
умеют предложить хороший вопрос, но уверенно выдумывают ссылки и искажают числа.
Здесь модель — исполнитель, а не источник знаний: ей выдают найденные документы, а каждое её
слово проверяет код.

## Как устроена защита от галлюцинаций

| Замок | Что делает |
|---|---|
| 1. Анкета слайда | Модель заполняет строгую форму; числа сверяются вторым каналом |
| 2. Закрытый мир | Документы находит код (PubMed, Europe PMC, ClinicalTrials.gov); модель видит только их |
| 3. Схема ответа | Каждое утверждение = ссылка на найденный документ + дословная цитата |
| 4. Проверка кодом | Документ существует; цитата буква в букву есть в тексте; числа есть в цитате |
| 5. Независимый судья | Три модели решают, поддерживает ли цитата утверждение |
| 6. Показ и журнал | Показывается только прошедшее; отброшенное доступно с причиной; всё воспроизводимо |

**Числа только цитатой:** в тексте, который пишет модель, цифр нет — любое число живёт
внутри дословной цитаты источника.

Подробно — [`docs/Архитектура — учебник.md`](docs/Архитектура%20—%20учебник.md);
почему именно так — [`docs/Журнал решений.md`](docs/Журнал%20решений.md).

## In English

**Fak(t) the check** — a personal Android web app for oncology conference moderators.
Photograph a slide and get questions and comments for the speaker in 15–35 seconds.
Every factual claim is backed by a verbatim quote from a retrieved source (PubMed,
Europe PMC, ClinicalTrials.gov, Russian clinical guidelines), and the quote is verified
by code, not by the model: closed-world retrieval, schema-forced citations, exact-match
quote checks, numbers allowed only inside quotes, and an independent entailment judge.
Built as a step-by-step learning project. Not a medical device. MIT license.
