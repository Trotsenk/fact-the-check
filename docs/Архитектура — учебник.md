# «Фак(т) зе чек» — архитектура и план обучения

Версия 1 от 19.09.2026. Это карта проекта: один раз прочитать целиком, дальше пользоваться
как справочником. Почему устроено именно так — в `Журнал решений.md` (номера решений указаны
в скобках).

---

## 1. Что строим — одной фразой

Приложение на телефоне: вы нажимаете «снять» на слайде доклада и через 15–35 секунд видите
вопросы и комментарии для докладчика, где **каждое утверждение опирается на дословную цитату
из проверенного источника**.

---

## 2. Путь одного снимка

```text
ТЕЛЕФОН   нажали «снять» → фото сжато до 1568 точек (200–400 КБ)            1–3 с
   │
   ▼
СЕРВЕР    приём: фото сохранено, задача поставлена в очередь
   │
   ├─ 1. ЧТЕНИЕ слайда                     модель Haiku 4.5              3–8 с
   │     → анкета: препараты, исследования, числа, главный вывод слайда
   ├─ 2. ПОИСК                             код, без модели               2–5 с
   │     → PubMed · Europe PMC · ClinicalTrials.gov · ASCO/ESMO · российский корпус
   │     → пронумерованный список документов Д1…Дn
   ├─ 3. СОСТАВЛЕНИЕ карточек              модель Sonnet 5               5–15 с
   │     → каждое утверждение = ссылка на Дk + дословная цитата
   ├─ 4. ПРОВЕРКА                          код, без модели               < 1 с
   ├─ 5. СУДЬЯ                             Haiku + MiniCheck + HHEM      2–5 с
   └─ 6. ПОКАЗ                             прошедшее → лента, остальное → «отброшенное»
   │
   ▼
ТЕЛЕФОН   карточки появляются по мере готовности; первая — через 10–15 с
```

Времена — оценка (ВЫВЕДЕНО), замер на уроке 17.

## 3. Шесть замков против галлюцинаций

**Главный принцип.** Модель — не источник знаний, а исполнитель. Ей выдают документы,
и каждое её слово проверяет код. Правило в инструкции — **просьба** (модель может ослушаться),
правило в коде — **закон** (его не обойти). Всё, что можно проверить кодом, проверяет код.

| Замок | Что делает | Кто | Что ловит |
|---|---|---|---|
| 1. Анкета слайда | Модель заполняет строгую форму; числа сверяются вторым каналом (второе чтение другим способом) | модель + код | неверно прочитанное число со слайда |
| 2. Закрытый мир | Код сам ищет документы; дальше модель видит **только** их | код | выдуманные статьи и номера PMID |
| 3. Схема ответа | Без поля «цитата» и ссылки на Дk карточка не собирается | модель по схеме | утверждения «из головы» |
| 4. Проверка кодом | Документ есть в списке и заново находится; цитата **буква в букву** есть в тексте; каждое число есть в цитате или на слайде | код | искажённые цифры, цитаты «своими словами», подменённые ссылки |
| 5. Независимый судья | Три голоса: Haiku, MiniCheck, HHEM — «поддерживает / нет / частично» | другие модели | настоящая статья, но не про то |
| 6. Показ и журнал | Показывается только прошедшее; у каждой фразы метка; журнал каждого шага | код | «незаметные» ошибки: всё воспроизводимо |

**Правило «числа только цитатой» (решение № 5).** В тексте, который пишет модель, цифр нет.
Любое число живёт только внутри дословной цитаты источника. Рядом — число со слайда:
расхождение видно глазами. Производное число (разность, NNT) — метка ВЫВЕДЕНО с формулой.

**Что остаётся риском даже при шести замках.**
- Нужная деталь есть только в полном тексте, а в абстракте её нет → «опора в абстракте не найдена».
- Тонкое искажение смысла, которое пропустил судья.
- Свежие данные конгресса, которых ещё нет в базах → «новее не нашёл».

**Почему это не паранойя.** В аудите 2,5 млн биомедицинских статей доля статей с выдуманными
ссылками выросла с 1 на 2 828 (2023) до 1 на 277 (2026) — The Lancet, 2026,
doi:10.1016/S0140-6736(26)00603-3 (статья ПРОВЕРЕНА через Crossref; числа — по пересказу).

## 4. Карточка

```text
ВОПРОС ДОКЛАДЧИКУ                                             ВЫВЕДЕНО
Как вы решаете вопрос об адъювантных циклах у пациенток с pCR?

  Опора  ПРОВЕРЕНО
  «…the estimated overall survival at 60 months was 86.6% …»
     ▲ число выделено  ·  на слайде: 86,6 %  ✓ совпадает
  Schmid P. et al., N Engl J Med 2024 · PMID 39282906 · DOI 10.1056/NEJMoa2409932
  ▸ показать абстракт (фраза подсвечена)
```

**Метки опоры (решение № 7):**

| Метка | Что это | Как выглядит опора |
|---|---|---|
| ПРОВЕРЕНО | Факт из исследования | цитата прошла замки 4 и 5 |
| НОРМА | Закон, приказ, клиническая рекомендация | цитата + номер документа + редакция и дата |
| СТАТИСТИКА | Заболеваемость, смертность и т. п. | ячейка таблицы: таблица, строка, столбец, год |
| МНЕНИЕ | Эксперт, журнал, консенсус | цитата + автор; **никогда не выдаётся за факт** |
| ВЫВЕДЕНО | Вопрос или вывод модели | строится только из проверенных опор |

Цитата — одна фраза, на языке источника. Перевод, если показан, помечен «перевод модели».

## 5. Источники

**Мировые (решение № 8).** PubMed, Europe PMC, ClinicalTrials.gov — «закрытый мир».
Сайты ASCO и ESMO — до 3 запросов на снимок, хранится только цитата и ссылка.
NCCN — только ссылка для ручной сверки. Открытый веб-поиск выключен.

**Российский контур (решение № 9).** 28 из 63 российских источников открываются только
с российского адреса, поэтому сбор идёт на вашем Mac:

```text
MAC (российский адрес)                          СЕРВЕР (Швеция)
┌────────────────────────────┐  синхронизация ┌───────────────────────────────┐
│ сборщики по расписанию     │ ─────────────► │ корпус документов:            │
│ (launchd, с догоном):      │                │ текст + таблицы + редакция    │
│ КР Минздрава, RUSSCO,      │                │ + дата + отпечаток SHA-256    │
│ ГРЛС, ЖНВЛП, КСГ,          │                │ полнотекстовый поиск SQLite   │
│ статистика, приказы,       │                └───────────────┬───────────────┘
│ российские журналы         │                                ▼ те же замки
└────────────────────────────┘
```

Очередь: (1) КР Минздрава и RUSSCO → (2) ГРЛС, ЖНВЛП, КСГ — до октябрьского эфира →
(3) статистика МНИОИ им. Герцена → (4) законы и приказы → (5) журналы и мнения.
Не используются: eLibrary (закрыт), Консультант, Гарант (коммерческие).

**Перекрёстные темы (решение № 10):** кардиоонкология, репродукция и фертильность, гериатрия,
инфекции, тромбозы, эндокринные осложнения, нефротоксичность, паллиатив, реабилитация.

| Часть | Технология | Зачем именно она (для новичка) |
|---|---|---|
| Страница | HTML + JavaScript + CSS | Работает в любом браузере, без сборщиков и установки |
| PWA | манифест + service worker | Иконка на экране, камера, «Поделиться», работа при плохой связи |
| Сервер | Python + FastAPI | Python вы знаете; FastAPI — простой способ принять фото по сети |
| База | SQLite | Один файл, ничего не нужно устанавливать; есть полнотекстовый поиск |
| HTTPS | Caddy | Сам получает и продлевает сертификат — без него телефон не даст камеру |
| Запуск | systemd | Перезапускает приложение после сбоя и перезагрузки |
| Код | git + GitHub | История изменений, резервная копия, выкладка одной командой |

## 7. Модель данных

```text
пользователь ─┐
              ▼
мероприятие ─► доклад ─► снимок ─► карточка ─► опора ─► документ
                          │           │                   (PMID/NCT/DOI или
                          │           └─ версия инструкции  российский документ,
                          └─ расход (токены, $, время)       редакция, SHA-256)
```

| Таблица | Главные поля |
|---|---|
| `users` | имя, роль (Иван / помощник), хэш пароля |
| `events` | название, дата, тема |
| `talks` | мероприятие, тема доклада, докладчик |
| `captures` | доклад, файл фото, время, статус разбора, анкета слайда (JSON) |
| `cards` | снимок, тип (вопрос / комментарий), текст RU, утверждение EN, метка, версия инструкции, отметка помощника |
| `supports` | карточка, документ, цитата, результаты замков 4 и 5, причина отброса |
| `documents` | источник, идентификатор, название, год, текст или абстракт, редакция, отпечаток |
| `prompt_versions` | текст инструкции, дата, хэш |
| `usage` | снимок, шаг, модель, токены, $, секунды |

## 9. Как доказываем, что работает

**Этап А — отладка** (после каждого изменения): 12 ваших фото + 10 ловушек + 10 слайдов
с изменённым числом + 200 автоматических подделок цитат и PMID.

**Этап Б — приёмка перед эфиром:** 50 настоящих + 30 ловушек + 20 с изменённым числом +
15 подмен (не та группа, не та линия, похожая аббревиатура).

**Ловушка** — слайд о несуществующем исследовании. Правильный ответ: «источник не найден».

| Что меряем | Порог (записан до прогона) |
|---|---|
| Поддельные цитаты и PMID пойманы кодом | 100 % |
| Ловушки: карточек ПРОВЕРЕНО | 0 |
| Изменённое число поймано | ≥ 90 % |
| Точность ПРОВЕРЕНО (судите вы) | ≥ 95 % |
| Настоящих слайдов ошибочно спрятано | ≤ 25 % |
| Показанное воспроизводится по журналу | 100 % |
| Согласие судьи с вами (150 пар) | κ ≥ 0,7 |

**Правило трёх.** Ноль провалов на N ловушках доказывает лишь, что частота провалов, вероятно,
ниже 3/N. На 30 ловушках — ниже ~10 %, на 100 — ниже ~3 %.

## 13. Словарь

- **API** — способ одной программы обращаться к другой по сети. Здесь — приложение к Claude.
- **Токен** — кусочек текста, которым модель считает объём; по токенам считается цена.
- **JSON** — текст в виде «поле: значение», который одинаково понимают люди и программы.
- **Схема (JSON Schema)** — описание обязательных полей; ответ модели без них отклоняется.
- **Инструкция (промпт)** — текст, который задаёт модели роль, правила и формат.
- **PMID / DOI / NCT** — номер статьи в PubMed / постоянный адрес статьи / номер исследования.
- **Абстракт** — краткое изложение статьи; для большинства статей это всё, что доступно бесплатно.
- **Судья (NLI)** — модель, которая решает, следует ли утверждение из цитаты.
- **Ловушка** — тест, на который правильный ответ «данных нет».
- **Нормализация** — приведение текста к одному виду (минусы, тире, пробелы) перед сравнением.
- **FastAPI** — библиотека Python для веб-сервера. **SQLite** — база данных в одном файле.
- **PWA** — сайт, который ставится на телефон как приложение.
- **HTTPS** — защищённое соединение; без него браузер не даёт доступ к камере.
- **SSH** — защищённый вход на сервер по ключу. **systemd** — служба Linux, которая держит
  программу запущенной.
- **git / коммит / репозиторий** — система версий / сохранённый снимок изменений / хранилище кода.
- **Пакетный режим API** — запросы без срочности, вдвое дешевле.
- **launchd** — планировщик задач на Mac.
