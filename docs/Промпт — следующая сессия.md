## 5. Задача сессии: урок 2б «Захват слайда» (решение № 28, этап v1)

Цель: фото телефона → найден слайд → выпрямлен → обрезан → оценено качество. Без ручных координат.

1. **Поиск рамки** (OpenCV): серый → размытие → края (Canny) → контуры → самый большой четырёхугольник
   (`approxPolyDP`), светлый внутри. Проверить на `olympia_phone_2000.jpg`: рамка ≈ ручной обрезке
   `(65, 300, 1815, 1290)`.
2. **Выпрямление:** `getPerspectiveTransform` + `warpPerspective` в прямоугольник 16:9 (или по сторонам рамки).
3. **Качество — три числа:** ширина слайда в точках, резкость (дисперсия лапласиана), пересвет (доля точек 255).
4. **Кривая «точность от ширины»** — порог объявить до расчёта. Бесплатная часть: OCR на уменьшенных
   копиях выпрямленного слайда → сколько чисел эталона находит (из 22). Платная часть (назвать сумму):
   Opus / Haiku + подсказка на тех же ширинах. Порог «зелёной рамки» — ширина, на которой чтение проходит
   № 27 + № 30.
5. **Испытание на фото Ивана:** на скольких найдена рамка; не найденные — отдельным списком с причиной
   (тёмный слайд, срезан край, блик). Запасной путь из № 28 — ручная рамка.
6. **Сломай и почини:** фото с отрезанным углом слайда; тёмный слайд; снимок под углом 30°.
7. **Итог:** коммит Ивана его командами (`python3 tools/check_public.py` перед коммитом; ноутбук без
   результатов ячеек); служебные правки Claude — отдельным коммитом с Co-Authored-By; файл урока
   `docs/уроки/02б Захват слайда.md`; этот промпт переписать на следующий урок.
