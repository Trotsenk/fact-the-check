## Задача сессии: урок 2

**Цель.** Измерить чтение слайда на эталоне OlympiA и найти вариант, проходящий порог (решение № 27),
или доказать, что нужен другой подход. Главный вопрос Ивана: «распознавание очень плохое — как с этим
работать?» — урок отвечает на него числами.

**Шаги** (каждый: зачем → понятия → диктант или задача → запуск → проверка):
1. **Модуль настроек (задача).** Иван создаёт `app/config.py`: своя `cost_usd`, таблица цен трёх моделей
   (Haiku 4.5 $1/$5, Sonnet 5 $2/$10, Opus 5 $5/$25 за 1 млн), словарь моделей по шагам. Понятия: модуль,
   импорт, путь поиска модулей. Свою заготовку из `private/ответы/` не показывать до его попытки.
2. **Эталон (диктант).** `tests/gold/olympia_2021.json` — что должно быть прочитано: название, ссылка,
   для IDFS и DDFS — разница с ДИ, HR, уровень интервала (99,5 %), границы, P («<0.001»), 3-летние значения
   по группам, события 106/178; отдельно — пункты «нет в тексте статьи» (точки кривых, подгруппы).
   Значения — только из абстракта и полного текста (адреса в файле урока 1). Понятия: JSON, словарь, список.
3. **Pillow.** Иван ставит сам: `python -m pip install pillow` (назвать размер, ≈ 3 МБ, и дождаться «да»).
   Понятия: размер картинки в точках, мегапиксели, почему API ужимает, нарезка на панели.
4. **Функция чтения (диктант → задача).** `read_slide(image, model, instruction)` → ответ + расход;
   результат каждого прогона пишется в файл `data/runs/…json` (МОО 47; папка `data/` не в git).
5. **Строгая анкета (диктант).** Структурированный ответ по схеме: название, ссылка, конечные точки
   (HR, уровень ДИ, границы, P), список «нечитаемо / сомнительно». Перед кодом свериться с навыком
   `claude-api` (Python: README и tool-use.md — structured outputs); не писать по памяти.
6. **Оценка (задача).** `score(ответ, эталон)` → «верно N из M · помечено сомнительным K · неверно без пометки L».
7. **Замер.** 3 модели × 2 картинки (целиком / нарезка на панели) = 6 прогонов на OlympiA; ≈ $0,10–0,25.
   Таблица результатов; сравнение с порогом. Цена каждого прогона печатается (МОО 44).
8. **Второй канал.** Два независимых чтения (разные модели или нарезки) → расхождения помечаются.
9. **Итог.** Какой вариант лучший на одном слайде; честно — одного слайда мало, полный тестовый набор —
   урок 8. Коммит Ивана (ноутбук без результатов, `app/config.py`, эталон); файл урока
   `docs/уроки/02 …md`; обновить этот промпт.
