## Задача сессии: урок 1

**Цель.** Рабочее окружение и первый вызов Claude из Jupyter с напечатанной ценой.
**Результат.** Приватный репозиторий `fact-the-check` на GitHub с первым коммитом; окружение
Python проекта; ключ API в `.env`; ноутбук `notebooks/01_первый_вызов.ipynb`, где Claude
отвечает на текст и на фото слайда, а под ответом печатаются токены, стоимость и время.

**Что Иван делает сам (руками, в браузере) — попроси в начале, по одному пункту:**
1. На GitHub создать **пустой приватный** репозиторий `fact-the-check` (без README).
2. В консоли Anthropic создать ключ API для этого проекта (имя `fact-the-check-dev`)
   и поставить лимит расходов $20 (решение № 12). Ключ **не вставлять в чат** — Иван
   положит его в `.env` сам.
3. По желанию — бесплатный ключ NCBI (PubMed пускает 10 запросов в секунду вместо 3);
   понадобится к уроку 3.

**Шаги урока (каждый: объясни зачем → покажи команду → Иван запускает → проверь результат):**

1. **Карта урока.** Одна схема: Mac → git → GitHub; Jupyter → `.env` → API Anthropic.
2. **Проверка окружения.** `python3 --version`, `git --version`, `git config user.name / user.email`.
3. **git.** Объясни: репозиторий, коммит, `.gitignore`. Создай `.gitignore`: `.env`,
   `.venv/`, `__pycache__/`, `.ipynb_checkpoints/`, `data/`, `tests/slides/real/`, `*.sqlite`.
   `git init`, первый коммит **явными путями**: `CLAUDE.md`, `docs/`, `.gitignore`.
4. **SSH-ключ для GitHub этого проекта.** `ssh-keygen -t ed25519 -C "fact-the-check" -f
   ~/.ssh/github_factcheck`; запись `Host github-factcheck` в `~/.ssh/config`. Иван добавляет
   публичную половину в GitHub (Settings → SSH keys). Проверка `ssh -T git@github-factcheck`.
   `git remote add origin git@github-factcheck:<аккаунт>/fact-the-check.git`, `git push`.
5. **Окружение Python.** `python3 -m venv .venv`. Перед установкой назови пакеты, источник
   (PyPI) и примерный размер, дождись «да»: `anthropic`, `httpx`, `python-dotenv`, `ipykernel`.
   Зарегистрируй ядро Jupyter `fact-the-check`.
6. **Секреты.** Создай `.env.example` с пустым `ANTHROPIC_API_KEY=`. Иван сам копирует его
   в `.env` и вставляет ключ. Проверка поиском, что `.env` не отслеживается git (МОО 41).
7. **`app/config.py`.** Таблица цен моделей (Haiku 4.5 $1/$5, Sonnet 5 $2/$10, Opus 5 $5/$25
   за 1 млн токенов) и модели по шагам (решение № 11) — одно место, откуда их берут все.
8. **Ноутбук `01_первый_вызов`.** (а) Текстовый вызов `claude-haiku-4-5`: печать ответа,
   `usage`, стоимости в $ и времени. (б) Вызов с фото слайда (любое фото Ивана или кадр
   с экрана): «Перечисли, что написано на слайде». Объясни, что такое токен, почему картинка
   стоит токенов, откуда берётся цена.
9. **Задание «сломай и почини».** Иван меняет имя модели на несуществующее и читает ошибку;
   переименовывает `.env` и читает ошибку авторизации; чинит оба случая.
10. **Проверь себя** (три вопроса, Иван отвечает словами):
    почему ключ не лежит в git; из чего складывается цена вызова; что сделает замок 4, если
    модель на шаге 3 напишет PMID, которого нет в списке Д1…Дn.
11. **Итог.** Коммит явными путями (`notebooks/01_…`, `app/config.py`, `.env.example`,
    `.gitignore`); файл урока `docs/уроки/01 Окружение и первый вызов.md` в формате урока
    (зачем → понятия → шаги → задание → проверь себя → итог); сводка: сколько стоили все
    вызовы урока. Обнови этот промпт на урок 2.
