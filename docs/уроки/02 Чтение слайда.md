# Урок 2. Замок 1: чтение слайда

Дата: 19.09.2026 (две сессии). Ноутбук: `notebooks/02_read_slide.ipynb`. Эталон: `tests/gold/olympia_2021.json`.

## Зачем

Карточка начинается с того, что система поняла, **какое исследование** на слайде и какие числа
показывает докладчик. Урок измеряет, насколько этому можно верить, и ищет, чем ловить ошибки.

```text
фото слайда ──► картинка (целиком / нарезкой) ──► модель заполняет бланк SlideReading
                                   │                         │
                                   └──► OCR (RapidOCR) ──────┴──► сверка: верно / null /
                                        второй канал               с пометкой / молча
эталон (tests/gold) ──────────────────────────────────────────────────────┘
```

## Понятия

| Понятие | Суть |
|---|---|
| Pillow: `size`, `crop`, `resize` | картинка как сетка точек; вырезать участок; уменьшить |
| Нарезка (`make_tiles`) | слайд на 4 части с перекрытием — модель видит мелкий текст крупнее |
| Бланк (Pydantic, `Field(description=…)`) | заранее заданная форма ответа; `messages.parse(..., output_format=…)` |
| `max_tokens` и размышления | Sonnet/Opus сначала думают; при малом потолке бланк обрывается |
| Эталон | верные значения, сверенные со **слайдом** (`on_slide`) и с публикацией |
| `flatten`, адрес `IDFS.hr` | вложенный бланк → плоский список «адрес → значение» |
| `.items()`, `continue`, `set`, `deepcopy` | пары ключ–значение; пропуск круга; мешок без повторов; полная копия |
| Четыре графы сверки | верно · null («не прочитано») · неверно с пометкой · неверно **молча** |
| `try` / `except` | ошибка одного вызова не останавливает весь замер |
| OCR, `.txts`, `.scores`, `.boxes` | распознанные строки, уверенность, рамки строк (4 угла) |
| Независимость каналов | второй канал полезен, только если ошибается иначе, чем первый |

## Главные находки (слайд OlympiA; ВЫВЕДЕНО: один слайд — наблюдение, не доказательство)

**Порог № 27 + № 30:** исследование опознано; неверных чисел молча ≤ 2 %; null ≤ 5 %.

| Модель, картинка | Прошли порог | Ошибок молча на прогон | $ за слайд | Время |
|---|---|---|---|---|
| Haiku 4.5, любая | 0 из 16 | 3–15 из 22 | ≈ 0,008 | 4–8 с |
| Sonnet 5, любая | 16 из 16 | 0 | ≈ 0,04 | 11–53 с (бюджет 35 с) |
| **Opus 5, любая** | **8 из 8** | **0** | ≈ 0,055 | 10–19 с |
| Haiku + подсказка OCR с координатами | 2 из 8 | 0–2 | ≈ 0,011 | 5 с |

- **Haiku ошибается местом, а не цифрами:** 95 (ДИ разницы) вместо 99,5; 0,607 (диаграмма подгрупп)
  вместо 0,58; значение соседней кривой.
- **RapidOCR** нашёл 22 из 22 чисел эталона на снимке экрана и 21 из 22 на фото (1–2 с, $0).
  Для сравнения Apple Vision — 16 и 9. OCR поймал 55 из 121 ошибки Haiku: **он подтверждает, что число есть
  на слайде, а не где оно стоит.** Ложных тревог на верных числах Opus — 4 из 176.
- **Подсказка OCR** сократила ошибки Haiku в 5–10 раз, но на фото ошибки OCR («873» вместо 87,5;
  «1.0» вместо 3,0 — уверенность 0,74 и 0,92) стали ошибками модели. При подсказке OCR перестаёт быть
  независимым каналом.
- **Ошибки измерения, найденные по дороге** (решение № 30): название сравнивалось строкой целиком
  («Olympiad» без «trial» считалось ошибкой); вторая DDFS из диаграммы подгрупп затирала панель B;
  порог без требования полноты пропускал прогон с 22 null.
- **Самопроверке модели верить нельзя:** Haiku помечает общие фразы, а не свои ошибки.
- **Слайд смешивает источники:** диаграмма подгрупп — Geyer et al., Ann Oncol 2022 (PMID 36228963),
  подписана как Tutt 2021; есть обновление Ann Oncol 2026 (PMID 42636977). Готовые примеры карточек
  «слайд против статьи» и «свежесть данных».

## Сломай и почини

- Бланк `Patient` с `age="шестьдесят"` → `ValidationError`: бланк не принимает не то.
- Испорченная копия ответа (`deepcopy`, HR 0,85 и ДИ 95 %) → `score` показал обе ошибки; без `deepcopy`
  испортился бы сам сохранённый ответ.
- Настоящая поломка: `max_tokens=4096` — Sonnet израсходовал его на размышления, бланк оборвался
  (`EOF while parsing`). Библиотека при этом **падает**, а не возвращает `None` — проверка `is None` не
  сработала. Лечение: потолок 16 000 и `try` / `except` со списком отказов.
