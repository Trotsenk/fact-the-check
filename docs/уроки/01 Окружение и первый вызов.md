# Урок 1. Окружение, репозиторий, первый вызов Claude

Дата: 19.09.2026. Ноутбук: `notebooks/01_first_call.ipynb`.

## Зачем

Подготовить мастерскую — где хранится код (git), где он лежит в интернете (GitHub) — и научить
программу говорить с Claude, с первого вызова видя, **сколько он стоит**.

```text
Mac: папка проекта ── git ── push ──► GitHub (fact-the-check)
     Jupyter ── ноутбук ── запрос ──► API Anthropic
     .env (ключ) — не в git
```

## Понятия

| Понятие | Суть |
|---|---|
| git, коммит, `.gitignore` | журнал версий; снимок изменений с подписью; список того, что git не видит |
| SSH-ключ, ключ развёртывания | пара «приватная на Mac — публичная на GitHub»; ключ, привязанный к одному репозиторию |
| Виртуальное окружение `.venv` | отдельная «коробка» библиотек проекта; ядро Jupyter «Python (fact-the-check)» |
| Переменные окружения, `.env` | настройки «имя = значение» для программы; ключ читается из файла, а не пишется в код |
| Клиент, `messages.create` | объект для обращения к Claude; отправка разговора списком реплик |
| Токены, `usage` | единица объёма текста; поля `input_tokens`, `output_tokens` — основа цены |
| Функция, параметр, `return` | правило в одном месте; функция работает только со своим входом |
| base64, блок-картинка | запись байтов картинки буквами; сообщение из блоков «картинка + вопрос» |

## Главная находка урока: как модель прочитала плотный слайд

Слайд — результаты OlympiA (Tutt ANJ et al., N Engl J Med 2021). Модель `claude-haiku-4-5`,
задача «перечисли всё, что на слайде». Сверка с публикацией: абстракт PubMed PMID 34081848,
doi:10.1056/NEJMoa2105215, и полный текст PMC9126186.

- Проверено 24 утверждения модели: **верно 7, неверно 17**.
- **Поправка 19.09.2026 (урок 2).** Сверка шла с публикацией, а не со слайдом. «Olympiad» и подпись
  анализа подгрупп не той конечной точкой модель прочитала верно — это ошибки самого слайда. По отношению
  к слайду: было «верно 7 из 24», стало **верно 9 из 24**. Эталон урока 2 сверяет со слайдом
  (`tests/gold/olympia_2021.json`, поле `on_slide`).
- Ошибки: название («Olympiad»), HR 0.53 вместо 0.58 и 0.58 вместо 0.57, интервал 95 % вместо 99,5 %,
  «P=0.001» вместо «P<0.001», перепутанные группы в 3-летних значениях (нашёл Иван), подгруппа HER2+
  в исследовании только HER2-отрицательных, подпись анализа подгрупп не той конечной точкой.
- Не проверено по тексту статьи: точки кривых, числа под риском, HR подгрупп — есть только на рисунках.
- Причины (ВЫВЕДЕНО): снимок 1942 × 1302 (2,5 Мп) API ужимает до ~1,15 Мп; три плотные панели;
  самая слабая модель; задача без структуры и без права сказать «нечитаемо».

Вывод: цифра со слайда не может быть фактом в карточке. От чтения слайда нужно опознать исследование;
числа — только из цитаты источника (замок 4). Порог для шага чтения — решение № 27.

## Сломай и почини

- Несуществующая модель → `NotFoundError`; неверный путь к `.env` при чистом ядре → `TypeError` у `None`.
- Функция, читающая `response.usage` вместо своего параметра `usage`, для второго вызова вернула цену
  первого: код не падает, число правдоподобно — и неверно.

## Проверь себя (ответы Ивана и поправки)

1. Ключ — секрет. **Дополнение:** код уходит в публичный репозиторий, история git вечна; `.env` в `.gitignore`.
2. Токены входа и выхода. **Дополнение:** умноженные на цену конкретной модели; картинка — тоже токены входа.
3. Замок 4 блокирует число, которого нет в источнике. **Поправка:** вопрос был о PMID — код проверяет, что
   документ есть среди найденных и заново находится в PubMed; иначе карточка отброшена с причиной.
