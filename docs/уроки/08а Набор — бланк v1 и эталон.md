# Урок 8а. Набор: бланк v1 и эталон (19.09.2026)

Ноутбук: `notebooks/08a_dataset.ipynb`. Модули: `app/capture.py`, `app/ocr.py`. Решения № 33–37.
Эталон набора — `data/gold_set/` (не в git: расшифровка чужих слайдов, правило 36а).

## Зачем

Все выводы уроков 2 и 2б стояли на одном слайде OlympiA. Нужна серия слайдов с эталоном, чтобы пороги
№ 27/36, выбор модели (№ 31) и захват (№ 32) стали выводами, а не наблюдениями.

## Понятия

| Понятие | Суть |
|---|---|
| Бланк v1 (`SlideFacts`, `Fact`) | любой слайд — список фактов: показатель (из списка) · конечная точка · группа · значение как напечатано · ДИ · срок |
| `Literal[...]` | графа с выбором из списка — сравнивается точно |
| Модуль (`app/capture.py`, `app/ocr.py`) | файл с функциями, который подключают `import`; одна копия кода на все ноутбуки и сервер |
| Пакетный режим (Message Batches) | 30 запросов разом, −50 % цены, ответ не сразу; бирка `custom_id`, ответы в любом порядке |
| Два независимых черновика | Opus и Sonnet; расхождения — место сверки; эталон по одному черновику подсуживает его (№ 34) |
| Таблица сверки | совпало / группа разная / место разное / только A / только B + «видит ли OCR» |
| Ключевые утверждения | 3–6 на слайд: конечная точка · сравнение · направление и величина (№ 36) |

## Что сделано

1. Бланк v1; контроль на OlympiA: черновик Opus — 22 из 22 чисел эталона урока 2 на месте ($0,19, 73 факта);
   Haiku + подсказка OCR — 9 из 22 ($0,033): путает конечную точку и группы в свободном списке (№ 34).
2. Модули `capture` и `ocr`; набор 15 слайдов через `capture` (14 «весь кадр» / «рамка», 15 из 15).
3. Пакет 30 черновиков (Opus + Sonnet × 15) отправлен — к концу сессии ещё в очереди (> 1,5 ч, 0 из 30).
4. Обычными вызовами — 3 слайда × 2 модели ($0,354): Opus и Sonnet согласны на 54 из 61 факта, все расхождения —
   в названиях, не в числах.
5. Эталоны: OlympiA, SERENA-6, EV-302 (с вопросами Ивана вслепую); Peak — без вопросов (если сохранён).
6. Поиск источников по 14 слайдам (агент + проверка Claude по PubMed для OlympiA, SERENA-6, EV-302).
7. Черновик «Линзы эксперта» — `docs/Линзы эксперта — черновик.md` (№ 37).

## Находки

- **Слайд против источника** (ПРОВЕРЕНО): OlympiA — p гетерогенности 0,698 и 79,6 % в Geyer 2022 Fig. 2C; диаграмма
  подгрупп подписана Tutt 2021. SERENA-6 — p < 0,00001 на слайде, < 0,0001 в NEJM 2025. EV-302 — обновление:
  HR ОВ 0,47 (NEJM 2024) → 0,53 (ASCO 2026).
- **Ошибка Opus без пометки**: 79,8 вместо 79,6 (размытая цифра) — найдена только сверкой с источником.
- **Название исследования на слайде часто не напечатано** (SERENA-6, EV-302, Peak): опознание — отдельный шаг
  по содержанию + поиск (замок 2).
- **Разброс (range) попадает в графы ДИ** — бланку нужна отдельная графа.
- **Идея Ивана**: проверка «значение внутри своего ДИ» — логическая проверка кодом (в замок 4).

## Замер чтения на наборе (решения № 36, 39)

Эталон — 15 слайдов, 66 ключевых утверждений (`data/gold_set/`). Код сравнивает утверждение с чтением модели
(«верно / место другое / число другое / нет»); флажки «место другое» Claude разобрал вручную — часть из них
разные подписи одного и того же (ложные тревоги кода).

| Читатель | Прогонов | Слайдов без принципиальных ошибок | Порог | $ на слайд |
|---|---|---|---|---|
| Opus 5 | 2 | 27 из 27 | 95 % — да | ≈ 0,07 |
| Sonnet 5 | 2 | 25 из 29 | нет | ≈ 0,05 |
| Haiku + OCR | 1 | 13 из 15 | 95 % — нет; 85 % (быстрый режим) — экзамен на новой партии | ≈ 0,014 |

- Самое трудное — привязка числа, а не цифра: на ALKOVE-1 популяцию «после ALK-ИТК» спутали со «всеми» Sonnet и Haiku.
- Решение № 39: быстрый режим (Haiku + OCR) — приоритет, с меткой и вторым каналом для ключевых утверждений;
  точный режим — Opus по запросу. Порог быстрого режима ≥ 85 % объявлен до экзамена на новой партии.
- Метрика кода грубая (подписи «Dost + CP» против «Dostarlimab + CP»): флажок — кандидат, решает человек.
