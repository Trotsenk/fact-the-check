Личное приложение · учебный проект · версия 1 от 19.09.2026

Фак(т) зе чек

Вы снимаете слайд доклада и через 15–35 секунд получаете вопросы и комментарии для докладчика. Каждое утверждение опирается на дословную цитату из проверенного источника.

  1. 0Снимокодно касание, фото 200–400 КБ1–3 с
  2. 1ЧтениеHaiku заполняет анкету слайда3–8 с
  3. 2Поисккод: PubMed, реестры, корпус РФ2–5 с
  4. 3КарточкиSonnet: утверждение + цитата5–15 с
  5. 4–5Проверкакод, затем три судьи2–5 с
  6. 6Лентапрошедшее; остальное — в «отброшенное»по мере готовности

Главное

Шесть замков против выдуманных ссылок

Модель — не источник знаний, а исполнитель. Ей выдают документы, а каждое её слово проверяет код. Правило в инструкции — просьба, правило в коде — закон.

  1. 1

    Анкета слайдамодель + код

    Модель заполняет строгую форму: препараты, исследования, числа как на слайде. Числа сверяются вторым каналом.

    Ловит: неверно прочитанное число.
  2. 2

    Закрытый миркод

    Документы находит код. Дальше модель видит только их, пронумерованными Д1…Дn.

    Ловит: выдуманные статьи и номера PMID.
  3. 3

    Схема ответамодель по схеме

    Карточка собирается только с полями «ссылка на Дk» и «дословная цитата».

    Ловит: утверждения «из головы».
  4. 4

    Проверка кодомкод

    Документ заново находится; цитата буква в букву есть в тексте; каждое число есть в цитате или на слайде.

    Ловит: искажённые цифры, пересказ вместо цитаты, подменённые ссылки.
  5. 5

    Независимый судьятри модели

    Haiku, MiniCheck и HHEM отвечают: поддерживает цитата утверждение, нет или частично.

    Ловит: настоящую статью «не про то».
  6. 6

    Показ и журналкод

    В ленте только прошедшее, у каждой фразы метка; журнал каждого шага позволяет воспроизвести результат.

    Ловит: незаметные ошибки — всё можно перепроверить.
Числа только цитатой. В тексте, который пишет модель, цифр нет. Любое число живёт внутри дословной цитаты источника, рядом — число со слайда. Производные числа помечаются ВЫВЕДЕНО с формулой.

Откуда опоры

Источники

Мировые

  • PubMed, Europe PMC, ClinicalTrials.gov
  • Сайты ASCO и ESMO — до 3 запросов на снимок, храним только цитату и ссылку
  • NCCN — только ссылка для ручной сверки

Открытый веб-поиск выключен: чем уже мир, тем меньше дыр.

Российский контур

  1. Клинические рекомендации Минздрава, RUSSCO
  2. ГРЛС, ЖНВЛП, схемы КСГ — до октябрьского эфира
  3. Статистика МНИОИ им. Герцена
  4. Законы и приказы
  5. Журналы и мнения экспертов

28 из 63 источников открываются только с российского адреса, поэтому сбор идёт на Mac, а корпус синхронизируется на сервер.

Словарь

Слова, которые встретятся

Модели и запросы
API
способ одной программы обращаться к другой по сети
Токен
кусочек текста, которым модель считает объём; по токенам считается цена
Инструкция (промпт)
текст, задающий модели роль, правила и формат
Схема JSON
список обязательных полей; ответ без них отклоняется
Судья
модель, которая решает, следует ли утверждение из цитаты
Источники и проверка
PMID / DOI / NCT
номер статьи в PubMed / постоянный адрес статьи / номер исследования
Абстракт
краткое изложение статьи — чаще всего это всё, что доступно бесплатно
Ловушка
тест, на который правильный ответ — «данных нет»
Нормализация
приведение текста к одному виду перед сравнением: минусы, тире, пробелы
Сервер и код
FastAPI / SQLite
веб-сервер на Python / база данных в одном файле
PWA
сайт, который ставится на телефон как приложение
HTTPS
защищённое соединение; без него браузер не даёт камеру
SSH / systemd
вход на сервер по ключу / служба, которая держит программу запущенной
git / коммит
система версий / сохранённый снимок изменений
