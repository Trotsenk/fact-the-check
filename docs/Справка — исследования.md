## 1. Рынок: готового решения нет

- Никто не делает цепочку «фото слайда → анализ → проверяемые ссылки → вопросы докладчику →
  архив по мероприятиям». Вопросов и возражений докладчику не генерирует никто. ПО ПЕРЕСКАЗУ.
- **Glass for Clinicians** — единственное клиническое ИИ-приложение, принимающее фото
  (подтверждено для iOS; для Android не упомянуто) и отвечающее со ссылками PubMed/DOI;
  бесплатный уровень, NPI не обязателен. ПО ПЕРЕСКАЗУ.
- **OpenEvidence** фото не принимает («Image-only documents… photographs are not supported»),
  заблокирован в ЕС и Великобритании с апреля 2026 — Lancet Reg Health Eur 2026,
  doi:10.1016/j.lanepe.2026.101718 (ПРОВЕРЕНО через NCBI).
- **Whova** — единственное приложение участника конгресса с фото слайда в заметки сессии.
- Близкий опыт: Gemini 2.0 Flash верно извлекал данные ссылок с 651 постера ASCO 2024 в 91,9 %,
  но связать с базой удалось 63,4 % — JMIR AI 2026, doi:10.2196/78148 (статья ПРОВЕРЕНА, числа
  ПО ПЕРЕСКАЗУ). OpenEvidence: 4 979 ссылок без выдуманных — npj Health Syst 2026,
  doi:10.1038/s44401-026-00142-8 (ПРОВЕРЕНА).
- Съёмка слайдов для личного использования: ASCO, AACR, ASH разрешают без вспышки; у ESMO
  запрет найден только на странице для сторонних медиа, правило для участников [U].

## 5. Android и PWA (для уроков 13–15)

- Установленная PWA в Chrome на Android принимает фото из «Поделиться» (Web Share Target,
  manifest: `method: POST`, `enctype: multipart/form-data`, `params.files`). Камера:
  `getUserMedia` и `<input type=file accept=image/* capture>`. Web Push и Background Sync работают.
- Тихая съёмка из фона на Android 14+ заблокирована; триггер «новое фото» ненадёжен.
- Своя картинка на системной заставке PWA невозможна: Chrome рисует её из манифеста
  (`name`, `background_color`, иконка 512). Своя анимация — только внутри страницы.
- Установка своего APK в РФ и ЕС пока без ограничений; обязательная проверка разработчиков
  с 30.09.2026 — только Бразилия, Индонезия, Сингапур, Таиланд.
